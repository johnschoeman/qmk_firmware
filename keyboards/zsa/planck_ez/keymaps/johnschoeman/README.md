# Planck EZ

## Dependencies

https://github.com/qmk/qmk_firmware/pull/25652

```
nix-shell -p qmk --run "qmk clone"
cd qmk_firmware
# Link .envrc file
ln -s ./util/nix/envrc ./.envrc
direnv allow
```

## Configure qmk

```
qmk
qmk config
qmk setup
qmk config user.keyboard=planck/ez
qmk config user.keymap=johnschoeman
```

## Compile and flash

```
qmk compile
qmk flash
```
